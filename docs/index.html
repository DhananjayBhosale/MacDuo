Native Apple silicon and Intel downloads · macOS 13+ · Compatible lid sensor required

MacBook compatibility · macOS 13+

Expected to work: MacBook Air with M2 or newer, and 14-/16-inch MacBook Pro with M1 Pro/Max or newer.

Intel preview: 2019 16-inch MacBook Pro. Physical Intel verification is pending.

Unsupported: M1 MacBook Air, 13-inch MacBook Pro with M1 or M2, and Intel models with only an open/closed clamshell switch.

Built for macOS 13; tested on an M4 MacBook Pro running a newer macOS. Physical Ventura and Intel testing are pending. Mac Duo checks for a compatible lid sensor; external displays are not animated.

A MINUTE TO GET STARTED

Download. Drag. Open.

  1. Download and move.

    Open Mac-Duo.dmg for Apple silicon or the Intel preview, then drag Mac Duo into Applications.

  2. Allow the first launch.

    Try opening Mac Duo. This release is not notarized, so macOS may show “cannot be opened” or “Apple could not verify.” Go to System Settings → Privacy & Security → Security → Open Anyway for Mac Duo, then confirm Open. Apple’s guide ↗

  3. Let it follow your lid.

    Click Enable Mac Duo and allow Screen Recording when prompted. Reopen if macOS asks. Frames stay in memory on your Mac. Try Replay without permission first.

Mac Duo supports English, Simplified Chinese, Traditional Chinese and Japanese. You can opt in to Open at login; login launches start paused, and the menu-bar icon can be hidden. Use Check for Updates… → Install & Relaunch for architecture-aware future updates. If macOS blocks an update, use Privacy & Security → Open Anyway, then retry in the recovery dialog or restore the previous app. Checks contact GitHub only when you ask; no desktop frames leave your Mac. For a manual update, quit the app before replacing it. Prefer a ZIP? All downloads and checksums ↗
